## 기능
| F-ID / R-ID | 범위·선행 기능 | 파일·함수 | 예상 시간 | 구현·연결 | 자동 검증 | 사용자 확인 | T-ID·근거 |
|---|---|---|---|---|---|---|---|

구현: 예정 / 구현 중 / 연결 완료 / 차단됨.
자동: 미실행 / 통과 / 실패 / 차단 / 재검증 필요 / 해당 없음(이유).
사람: 미확인 / 확인 완료 / 수정 필요 / 재확인 필요 / 해당 없음(이유).
전체 완료 = 필수 동작 연결 + 현재 유효한 필수 검사 + 필요한 사람 확인 + 차단 없음.
도구 status를 확인한 뒤 이 표를 갱신한다. 도구가 이 표를 자동 수정하지는 않는다.
