# 실행 근거 색인

초기 상태: 실제 과제 검사는 아직 실행하지 않았다.
도구가 실행별 result.json·output.log를 만들고 아래에 링크를 추가한다.
과거 결과는 역사이며 현재 적용 가능성은 `python3 tools/check.py status`로 확인한다.
로그에는 민감정보를 출력하지 않는다. 외부 공유 전 원문도 확인한다.

각 result.json: 범주·F/T-ID·명령·cwd·시각·환경·입력/코드 지문·Git 상태·기대/관찰·종료 코드·검사 개수·원본 상태.
수동 확인은 실행 대기 시점의 지문, 확인자, 실제 관찰, caller 보고임을 기록한다.
