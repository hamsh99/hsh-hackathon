# 전체 계획

## 한눈에 보기

- **왜 만드는가**　PROBLEM의 업무 문제를 한 문장으로 적는다.
- **어떻게 풀 것인가**　사용자가 최종 결과를 받기까지의 작업 순서를 짧게 적는다.
- **지금 할 일**　진행 중인 라운드의 목표와 바로 다음 행동을 적는다.
- **내 판단이 필요한 일**　있을 때만 이유와 선택지를 적는다.

## 범위와 기록 위치

- 필수 산출물·실행 환경·마감과 검증 시간은 원문 또는 실제 확인 범위에서 기록한다.
- 제외하거나 보류한 일이 일정에 영향을 줄 때만 이유를 적는다.
- 업무 조건은 PROBLEM, 구현·검사 근거는 해당 라운드, 최종 검증·복습·제출 준비는 REVIEW의 실제 위치로 안내한다.

## 라운드 전 인계

첫 라운드 전에 중단할 때만 확인 시각·현재 근거·차단·첫 행동을 남긴다. 라운드를 시작하면 현재 라운드의 인계 위치만 적는다.
