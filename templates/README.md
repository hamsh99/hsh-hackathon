# 과제 실행 안내

제품 실행 명령: 아직 미확정. 실제 프로젝트 확인 후 입력.
제품 확인 주소 또는 CLI/파일 경로: 아직 미확정.
공식 제출 방식·필수 파일: 아직 미확정.

## 하네스
시작: `harness/START.md`.
환경: `python3 tools/doctor.py`.
상태: `python3 tools/check.py status`.
검사: `python3 tools/check.py run T-001` (실제 T-001 설정 후).
제출 점검: `python3 tools/check.py release` (업로드하지 않음).

## 기록
- docs/TASK.md: 요구사항·계약·현재 상태
- docs/STATE.md: 현재·다음 행동
- docs/DECISIONS.md: 선택 이유·코드 흐름
- docs/EVIDENCE.md: 실제 실행 근거

하네스를 적용한 것과 제품을 구현·검증한 것은 별개다.
