# 이 과제는 무엇을 해결하나요?

누가 무엇을 하려는지 한 문장으로 말한다. 이어서 원문 속 사람 한 명의 상황을 따라가며, 어떤 일이 생기고 무엇을 판단하기 어려운지 짧은 문단으로 설명한다. 사람이 왜 곤란한지 먼저 보여주고, 그다음 서비스가 어떤 판단을 도와주는지 말한다.

낯선 용어는 등장한 자리에서 풀어 준다. 여러 용어를 비교해야 할 때만 짧은 불릿을 쓴다. 실제 업무 조건은 원문을 따르고, 이해를 위해 만든 상황과 숫자는 설명용이라고 표시한다.

## 만들고 나면 무엇이 보이나요?

같은 사람이 무엇을 선택하고 어떤 결과를 읽는지 작은 예시로 이어준다. 표가 핵심이면 행·열의 뜻을 알 수 있게 몇 칸만 채운다.
