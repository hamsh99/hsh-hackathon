# 하네스 v1 구축 상태

이 문서는 하네스 자체 개발 기록이다. 과제용 빈 문서는 templates/docs/에 있다.
제품 서비스는 구현하지 않았으며, 실제 과제의 R/F/T-ID는 설치 후 별도로 작성한다.

## 사용자 결정
- 제출은 과제 폴더 유지와 제출 범위 목록을 기본안으로 한다. 공식 지시 확인 시 맞춘다.
- 제품 AI 연동은 조건부로 두며 개발용 Codex와 분리한다.
- 사용자 요청으로 계획 단계에서 실제 하네스 구축 단계로 전환했다.

## 구현 현황
| 기능 | 요구·성공 조건 | 실제 경로 | 검증 | 상태 |
|---|---|---|---|---|
| F-001 | 기존 파일·설정·Git 스테이징을 보존하며 적용 | install.py | installer 관련 회귀 검사 | 연결 완료 / 자동 통과 / UI 해당 없음 |
| F-002 | 실행 환경·실제 검사·예제·하네스 범주 구분 | tools/doctor.py, check.py, _unittest_runner.py | 환경·0개·skip·오류·시간 초과 검사 | 연결 완료 / 자동 통과 / UI 해당 없음 |
| F-003 | 실행 증거·변경 지문·수동 확인·최신 상태 | tools/_core.py | stale·기록 유지·수동 대기 검사 | 연결 완료 / 자동 통과 / UI 자동화 아님 |
| F-004 | 원본 보존과 실행별 임시 정리 범위 제한 | tools/_core.py | 원본 전후·마커·링크·경로 검사 | 연결 완료 / 자동 통과 / UI 해당 없음 |
| F-005 | 실제 과제 검사와 최종 사람 검토 없이 제출 준비 판정 금지 | tools/_core.py: release | release·범주·파일 누락·비밀 파일 검사 | 연결 완료 / 자동 통과 / 제품 적용은 미실행 |

## 범위와 한계
- 실제 서비스·개발용 UI·웹 서버·외부 AI 호출·공식 플랫폼 제출은 포함하지 않는다.
- 단일 세션·Python 표준 라이브러리로 운영한다. 정식 SKILL 패키지·MCP·멀티에이전트는 추가하지 않았다.
- 과제별 검사 범위·기대값·필수 요구 매핑의 적절성은 사용자와 Codex가 확인한다.
- 검증 근거·H-01~H-18 대응은 VERIFICATION.md와 ACCEPTANCE.md를 참조한다.
